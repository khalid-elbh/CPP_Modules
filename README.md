# CPP_Modules

A collection of C++ projects from the **42 School** curriculum, covering core concepts of **Object-Oriented Programming (OOP)** in C++98.

## 📚 Overview

The CPP Modules are a series of progressively challenging exercises designed to introduce C++ and OOP principles to students coming from a C background. Each module focuses on specific language features and design patterns.

## 🗂️ Modules

| Module | Topics Covered |
|--------|---------------|
| **CPP00** | Namespaces, classes, member functions, stdio streams, initialization lists, static & const |
| **CPP01** | Memory allocation, pointers to members, references, switch statement |
| **CPP02** | Ad-hoc polymorphism, operator overloading, Orthodox Canonical Form |
| **CPP03** | Inheritance |
| **CPP04** | Subtype polymorphism, abstract classes, interfaces |
| **CPP05** | Repetition and Exceptions |
| **CPP06** | C++ casts |
| **CPP07** | C++ templates |
| **CPP08** | Templated containers, iterators, algorithms |
| **CPP09** | STL containers |

## 🛠️ Requirements

- C++ compiler supporting **C++98** standard (e.g., `g++`)
- `make` build tool

## 🚀 Usage

Each module contains its own set of exercises. Navigate into any exercise directory and build using:

```bash
make
./executable_name
```

## 📝 Notes

- All code follows the **C++98** standard as required by the 42 curriculum.
- The Orthodox Canonical Form (default constructor, copy constructor, copy assignment operator, destructor) is applied where relevant.
- No STL containers or algorithms are used before CPP08 (where explicitly introduced).
